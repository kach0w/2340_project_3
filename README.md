# 2340_project_3 — DisasterBot (RAG chatbot)

## Setup
```bash
python3.12 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser   # staff users get Knowledge Base / Monitoring pages
python manage.py runserver
```

## Apps
- `chat` — home/about, chat UI, RAG pipeline (`rag.py`), intent-based prompts (`prompts.py`)
- `knowledge` — documents + chunks, ingestion (file / URL / text), cleaning, clear & reload
- `monitoring` — query logs, latency/failure dashboard, accuracy evaluation
- `accounts` — signup / login / logout

## Location-filtered alerts (custom story 2)
- Staff can give any document an **Alert areas** value when adding or editing it:
  comma-separated 5-digit ZIPs (`30332, 30318`) or 3-digit ZIP prefixes (`303` = all
  of metro Atlanta). Leave it blank for general guidance that applies everywhere.
- Users set their ZIP in the bar at the top of the Chat page (saved on their
  profile when logged in, in the session for guests). Retrieval then skips alerts
  tagged for other areas, and the prompt tells the model the user's ZIP.
- With no ZIP set, nothing is filtered.

## Deployment (Render)
The repo ships a Render Blueprint (`render.yaml`) that creates the web service
(gunicorn + WhiteNoise for static files) and a free Postgres database.

1. Push this branch / merge to `main`.
2. On https://dashboard.render.com: **New → Blueprint**, pick this repo.
3. Fill in the prompted env vars: `GOOGLE_API_KEY`, `GEMINI_MODELS` (optional),
   and `DJANGO_SUPERUSER_USERNAME` / `_EMAIL` / `_PASSWORD` for the admin account.
4. Deploy. The app is served at `https://<service>.onrender.com`. Log in as the
   admin and load the knowledge base from **Knowledge Base**.

`build.sh` installs deps, runs `collectstatic` and `migrate`, and creates the
admin account. `SECRET_KEY` is generated by Render.

Production env vars (all optional locally): `DEBUG`, `SECRET_KEY`,
`ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`, `DATABASE_URL`. With none set, the app
runs exactly as before (DEBUG on, SQLite).
